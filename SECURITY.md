# Politique de sécurité

Ne publiez pas de vulnérabilité, de projet d'investigation, de rapport PhotoRec
ni de données de preuve dans une issue publique.

Signalez le problème de manière privée au mainteneur du dépôt, avec une
description reproductible, la version de CarvEx, le système d'exploitation et
le niveau d'impact. Un accusé de réception doit intervenir sous 7 jours.

CarvEx assiste une analyse DFIR ; il ne remplace ni une procédure d'acquisition
forensique, ni la conservation des originaux, ni une validation humaine des
résultats.
